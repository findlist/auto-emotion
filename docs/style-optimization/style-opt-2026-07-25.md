## 具体修改内容

### 1. 首页 · "更多功能"6 个按钮 emoji 圆形背景（home.tsx）

**问题**：首页"更多功能"区域的 6 个按钮（成就 / 好友 / 排行榜 / 通行证 / 商城 / 任务）的 emoji 以 `text-xl` 浮空展示在 `bg-cream` 卡片上，无任何背景容器。对比 07-20 轮已在挂机页武器/技能/宠物、商店页商品/背包、成就页状态 emoji 落地的圆形背景视觉模式，首页这 6 个按钮 emoji 缺乏同等视觉权重。玩家扫视 3×2 网格时，emoji 容易被卡片边框与下方文字淹没，无法快速定位功能入口。首页 header 的玩家头像（`w-12 h-12 rounded-full bg-pink`）已建立"圆形主体识别区"视觉模式，但"更多功能"区域的 emoji 未跟进同一模式，同一页面内视觉语言不一致。

**修改**：6 个按钮的 emoji（🏅 / 👥 / 🏆 / 🎖️ / 🛒 / 📋）均包裹进 `w-10 h-10 rounded-full bg-ink/5` 圆形容器：

```diff
- <span aria-hidden="true" className="text-xl">🏅</span>
- <span className="font-mono text-xs">成就</span>
+ {/* emoji 加圆形背景给视觉重量，与挂机页武器/技能/宠物、商店页商品/背包、成就页状态 emoji 视觉模式一致
+     更多功能按钮无状态差异，统一用 ink/5 中性底；w-10 h-10 比挂机页 w-12 小一档适配紧凑布局 */}
+ <div className="w-10 h-10 rounded-full bg-ink/5 flex items-center justify-center">
+   <span aria-hidden="true" className="text-xl">🏅</span>
+ </div>
+ <span className="font-mono text-xs">成就</span>
```

其余 5 个按钮（👥 好友 / 🏆 排行榜 / 🎖️ 通行证 / 🛒 商城 / 📋 任务）同款修改，仅 emoji 字符不同，圆形容器样式完全一致。

**设计原因**：
- **跨页视觉模式补齐**：07-20 轮已建立"emoji 圆形背景"视觉模式（挂机页 `w-12 h-12` / 商店页商品 `w-16 h-16` + 背包 `w-12 h-12` / 成就页 `w-12 h-12`），首页"更多功能"emoji 是该模式最后的缺口。补齐后整个应用的"主体识别区"视觉语言完全统一
- **同页视觉一致性**：首页 header 玩家头像（`w-12 h-12 rounded-full bg-pink`）已建立圆形主体识别区，"更多功能"emoji 现在共享同一视觉模式，首页内部视觉语言统一
- **`w-10 h-10` 尺寸克制**：比挂机页/成就页的 `w-12 h-12` 小一档，适配"更多功能"按钮的紧凑布局（`p-2 sm:p-3` + `gap-1`），不会因圆形过大挤压下方文字
- **`bg-ink/5` 中性底**：6 个按钮无状态差异（都是中性导航入口），统一用 `ink/5` 中性底避免色彩干扰；与挂机页未装备态 `bg-ink/5`、商店页商品 `bg-ink/5`、成就页未完成态 `bg-ink/5` 同源
- **`flex items-center justify-center`**：emoji 在圆形容器内水平垂直居中，避免因 emoji 字符的 baseline 间距导致视觉偏移
- **`aria-hidden="true"` 保留**：emoji 为装饰性视觉标识，功能名通过下方 `<span className="font-mono text-xs">` 文字朗读，避免冗余

## 设计原则总结

本轮遵循以下原则：

1. **视觉模式补齐 > 新装饰堆砌**：本轮修改的本质是"既有视觉模式在首页未落地"的修复——07-20 轮已在挂机页/商店页/成就页建立"emoji 圆形背景"视觉模式，但首页"更多功能"区域的 6 个按钮 emoji 是该模式最后的缺口。补齐后整个应用的"主体识别区"视觉语言完全统一，而非引入新装饰
2. **同语义同视觉**：首页 header 玩家头像、挂机页装备图标、商店页商品图标、成就页状态图标、首页"更多功能"按钮图标都是"主体识别"场景，应共享圆形容器视觉模式。语义相同的元素用相同视觉模式，是设计系统的基础原则
3. **复用既有 CSS 类**：本轮零新增 CSS 工具类，全部复用 Tailwind 内置类（`bg-ink/5`、`rounded-full`、`flex items-center justify-center`）。CSS 体积零增长
4. **尺寸差异化适配布局密度**：`w-10 h-10` 比挂机页/成就页的 `w-12 h-12` 小一档，适配"更多功能"按钮的紧凑布局（`p-2 sm:p-3` + `gap-1`）。圆形容器尺寸随布局密度调整，而非一刀切
5. **中性底避免色彩干扰**：6 个按钮无状态差异（都是中性导航入口），统一用 `bg-ink/5` 中性底；与挂机页未装备态、商店页商品、成就页未完成态的 `bg-ink/5` 同源，"中性态用 ink/5"色彩语义贯穿
6. **功能零侵入**：所有修改限于样式层（className、JSX 结构），业务代码一字不动；新增的 `<div>` 均为纯视觉展示，不参与状态管理
7. **小步增量**：本轮 1 处改动（涉及 1 个文件，6 个按钮同款修改，零 CSS 新增），独立可验证，遵循小步重构原则
