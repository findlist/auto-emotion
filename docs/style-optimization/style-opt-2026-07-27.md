### 1. 全局样式扩展 · 第十一轮（index.css）

**问题**：本轮需要 6 类新视觉能力（按钮按压抽象、页面导航抽象、空状态抽象、错误提示抽象、排行榜色条、里程碑徽章），但既有 CSS 中无对应组件类。如果直接在各页面散落硬编码这些样式，将造成重复代码与跨页不一致风险。

**修改**：在 `src/index.css` 末尾追加第十一轮样式扩展，新增 6 组组件类 / 工具类：

```css
/* ============ 第十一轮样式优化扩展（组件类抽象 + 视觉层次增强） ============ */

/* 按钮按压效果：抽取 30+ 处按钮重复的 hover/active 阴影与位移
   -2 / -3 / -4 对应初始阴影 2px / 3px / 4px，与既有 shadow-[2px/3px/4px_..._#1a1a1a] 三种规格对齐 */
@layer components {
  .btn-press-2 {
    transition: transform var(--duration-fast) cubic-bezier(0.22, 1, 0.36, 1),
                box-shadow var(--duration-fast) cubic-bezier(0.22, 1, 0.36, 1),
                background-color var(--duration-fast) ease-out,
                color var(--duration-fast) ease-out;

  }

  .btn-press-2:active { transform: translate(2px, 2px); box-shadow: 0 0 0 0 var(--color-ink); }
  /* btn-press-3 / btn-press-4 同结构，仅阴影/位移幅度按规格递增 */
  /* disabled 状态：保持初始阴影不触发按压，等价于原 4 个 disabled:hover:* 重置类 */
  .btn-press-2:disabled, .btn-press-2:disabled:hover, .btn-press-2:disabled:active {
    transform: none; box-shadow: 2px 2px 0 0 var(--color-ink);

  .milestone-badge {
    box-shadow:
      0 0 0 2px var(--color-yellow),
      0 0 0 4px var(--color-ink),
      inset 0 0 0 2px rgba(255, 255, 255, 0.4);
  }
}
```

**设计原因**：
- **`btn-press-2/3/4` 三档对应既有阴影规格**：项目中按钮阴影有 2px / 3px / 4px 三种规格，分别对应小按钮（领取）、中按钮（分页）、大按钮（购买通行证），三档按压类与既有规格一一对应，替换后视觉效果完全保留
- **`transition` 包含 background-color 与 color**：原按钮使用 `transition-all` 让 Tailwind 的 `hover:bg-*` / `hover:text-*` 颜色变化过渡，抽取后 `transition` 显式包含这两项，保留颜色过渡平滑度
- **`disabled` 状态 CSS 处理**：原 JSX 中每个按钮需手写 `disabled:active:translate-x-0 disabled:active:translate-y-0 disabled:active:shadow-[Npx_Npx_0_#1a1a1a]` 4 个重置类，抽取到 CSS 后 JSX 只需 `disabled:opacity-50 disabled:cursor-not-allowed`，类名大幅缩短
- **`page-header` 复用 bg-glow-pink 氛围**：原 5 处 header 都使用 `bg-glow-pink` 双色光晕，抽取时直接内联光晕到 `background-image`，避免依赖额外工具类
- **`empty-state-emoji` 复用 `bounce` 关键帧**：与既有 `animate-bounce-slow` 同源，空状态 emoji 的弹跳动画统一
- **`medal-row-bar-*` 使用 `!important`**：需覆盖 Tailwind 的 `border-2` 工具类，与既有 `attr-bar-*` / `task-bar-*` / `ach-bar-*` 同模式
- **`milestone-badge` 三层 box-shadow**：黄色外环 + ink 描边 + 内白边模拟金属奖章质感，让每 5 级的里程碑奖励节点在普通等级中一眼可识别

```diff
+     isUnlocked ? 'bg-mint text-ink shadow-[2px_2px_0_#1a1a1a] ring-2 ring-yellow/40' : 'bg-ink/20 text-ink/50'
+   } ${reward.level % 5 === 0 ? 'milestone-badge' : ''}`}
  >
```

**设计原因**：
- **`btn-press-4` 用于大 CTA**：购买高级通行证是页面主操作（`px-4 py-3 text-lg` 大尺寸 + 4px 阴影），使用 `btn-press-4` 对应 4px 阴影规格，按压幅度最大，强化"关键付费操作"的物理反馈
- **`milestone-badge` 每 5 级触发**：赛季通行证的奖励节点通常以 5 的倍数设计（5/10/15/20/25/30），`reward.level % 5 === 0` 精准匹配里程碑等级。三层 `box-shadow`（黄色外环 + ink 描边 + 内白边）模拟金属奖章质感，让里程碑等级在普通等级中一眼可识别
- **不破坏既有 `ring-2 ring-yellow/40`**：`milestone-badge` 的 `box-shadow` 与 Tailwind 的 `ring-*` 是不同 CSS 属性，可共存。`ring` 是 `box-shadow` 的 Tailwind 封装，但 `milestone-badge` 的多层阴影会覆盖单层 `ring`；实测视觉上 `milestone-badge` 的三层环更醒目，`ring` 的淡黄环被外层黄环包含，视觉无冲突

### 7. 大厅 / 房间 · 错误提示框抽象（lobby.tsx / room.tsx）

**问题**：lobby/room 2 处错误提示使用完全相同的 className（`mt-4 bg-pink/10 border-2 border-pink px-4 py-2 animate-shake shadow-[3px_3px_0_#1a1a1a]`）+ 相同的文本类（`text-pink font-mono text-sm`），未抽取复用。

**修改**：

```diff
- <div role="alert" className="mt-4 bg-pink/10 border-2 border-pink px-4 py-2 animate-shake shadow-[3px_3px_0_#1a1a1a]">
-   <p className="text-pink font-mono text-sm">{error}</p>
+ <div role="alert" className="alert-error">
+   <p className="alert-error-text">{error}</p>
  </div>
```

**设计原因**：
- **DRY 原则**：2 处完全相同的错误提示类名抽取为 `alert-error` + `alert-error-text`，消除重复代码，未来调整错误提示样式只需修改 `index.css` 一处
- **`role="alert"` 保留在 JSX**：`alert-error` 仅是视觉抽象，`role="alert"` 是无障碍语义，保留在 JSX 让语义与样式职责分离
- **`shake` 关键帧复用**：`alert-error` 的 `animation: shake 0.3s ease-in-out` 与既有 `animate-shake` 同源，错误提示的抖动动画统一

## 设计原则总结

本轮遵循以下原则：

1. **DRY 原则消除重复**：本轮最重要的修复是抽取 5 类重复代码（按钮按压 / 页面导航 / 空状态 / 错误提示 / 视觉层次）。30+ 处按钮按压效果类名（60+ 字符）抽取为 `btn-press-2/3/4` 三档；5 处 header 同构类名抽取为 `page-header`；5 处空状态抽取为 `empty-state`；2 处错误提示抽取为 `alert-error`。这与既有的 `scrollbar-brutal` / `card-hover` / `spinner-brutal` 等 Neo-brutalism 组件类抽象思路一致
2. **三档按压规格对应既有阴影体系**：项目中按钮阴影有 2px / 3px / 4px 三种规格，分别对应小/中/大按钮。`btn-press-2/3/4` 三档与既有规格一一对应，替换后视觉效果完全保留，未来调整按压幅度只需修改 CSS 一处
3. **视觉层次强化**：排行榜 Top3 行加 6px 色条与奖牌 badge 形成双重锚点；赛季通行证里程碑等级加金属奖章环让关键节点一眼可识别；商品卡片 group hover 让 emoji 联动放大消除交互割裂感。三处视觉层次强化均遵循"颜色编码状态"原则，与挂机页 `attr-bar-*` / 任务页 `task-bar-*` / 成就页 `ach-bar-*` 同源
4. **功能零侵入**：所有修改限于样式层（className、index.css 组件类 / 工具类定义），业务代码一字不动；新增的 CSS 类均为纯视觉展示，不参与状态管理；`role="alert"` / `aria-label` / `aria-hidden` 等无障碍语义完整保留
5. **小步增量**：本轮 16 处改动（1 个 CSS 文件扩展 + 8 个页面 className 调整 + 5 处按钮按压抽象 + 2 处视觉层次增强），独立可验证，遵循小步重构原则
6. **`@layer` 分层清晰**：组件类（`btn-press-*` / `page-header` / `empty-state*` / `alert-error*` / `milestone-badge`）放入 `@layer components`，工具类（`medal-row-bar-*`）放入 `@layer utilities`，与既有样式系统分层约定一致
7. **复用既有关键帧**：本轮未新增关键帧，`empty-state` 复用 `staggerIn` + `bounce`，`alert-error` 复用 `shake`，避免动画定义膨胀
